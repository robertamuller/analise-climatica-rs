# Climate Analysis of Rio Grande do Sul

Exploratory analysis of climate data in Rio Grande do Sul, Brazil, using ERA5-Land monthly data from 1990 to 2025.

### Libraries
- NumPy
- Pandas
- Xarray
- GeoPandas
- Rioxarray
- Shapely
- Matplotlib
- Seaborn
- CDSAPI

### Data Source
[Copernicus Climate Data Store (ERA5-Land)](https://cds.climate.copernicus.eu/)

*Work in progress.*
